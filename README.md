Bulut Bilişim - Kişisel Web Sayfası Projesi



Projenin Kısa Açıklaması

Bu proje, Bulut Bilişim dersi kapsamında hazırlanmış basit bir kişisel web sayfasıdır. Proje, web geliştirme temellerini içerir ve Docker kullanılarak konteynerize edilip GitHub Pages üzerinden yayınlanmıştır.

Docker Çalıştırma Komutları

Projeyi kendi lokal ortamınızda Docker ile çalıştırmak için aşağıdaki komutları sırasıyla terminalde çalıştırın:



1\. Docker imajını oluşturun:

`docker build -t webproje .`



2\. Docker konteynerini başlatın:

`docker run -d -p 8080:80 webproje`



Konteyner çalıştıktan sonra tarayıcınızdan `http://localhost:8080` adresine giderek projeyi görüntüleyebilirsiniz.
